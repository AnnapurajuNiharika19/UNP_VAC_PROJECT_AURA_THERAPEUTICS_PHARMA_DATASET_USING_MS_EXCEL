# UNP_VAC_PROJECT_AURA_THERAPEUTICS_PHARMA_DATASET_USING_MS_EXCEL
Aura Therapeutics – Pharma Distribution Analytics

This project focuses on analyzing pharmaceutical distribution data using Microsoft Excel, data preprocessing, statistical analysis, and regression techniques.

The project includes cleaning missing values, removing duplicate records, correcting inconsistent data, detecting outliers, creating pivot tables and charts, performing statistical tests such as T-test, Z-test, and ANOVA, and building simple and multiple linear regression models.

It also includes correlation analysis and 10 business insights to understand sales performance, product distribution, revenue trends, and business opportunities.

Tools & Technologies: Microsoft Excel, Pivot Tables, Charts, Statistical Analysis, Correlation, Linear Regression, Data Cleaning.

Objective: To transform raw pharmaceutical distribution data into meaningful insights that support better business decisions.
